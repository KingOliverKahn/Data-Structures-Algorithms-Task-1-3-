# DSA CAT Final Submission

This repository contains the three parts of the Data Structures and Algorithms CAT in the order required by the assignment.

## Task 1

Task 1 contains the analysis and design of the modern parking system, including the proposed modules, algorithms, data structures and dynamic database design.

## Task 2

Task 2 contains the functional web-based Modern Parking System. It is implemented in C++ with SQLite and uses a browser-based interface.

The system supports parking-slot availability, vehicle arrival, slot assignment, parking sessions, duration and fee calculation, payment, barrier authorisation and slot release.

## Task 3

Task 3 contains the factorial program using a manually implemented stack. It demonstrates forward factorial calculation and backward retrieval using LIFO behaviour, together with input validation and overflow handling.

## Verification

Task 2 was clean-built with CMake and its logic tests and end-to-end smoke test passed.

Task 3 was clean-built with CMake, its automated test passed, and the executable was run with both 5 and 0 as inputs.

The `build` directories are intentionally excluded from this submission. They are generated locally when the projects are compiled.
